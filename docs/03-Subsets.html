2  Subsetting and Indexing

An auditor rarely looks at every record in the same way. In the payment register of a works division, we want the payments above the Executive Engineer’s financial power of ₹5 lakh. We want the bills of one contractor. We want the rows where the amount is missing, and the payments to firms that are not on the approved list. Each of these is a small part of the register, picked out by a rule. Picking out such parts is called subsetting.

Much of audit analysis is subsetting. Every exception report begins with it. R gives us several ways to subset its objects, that is vectors, matrices, lists and data frames. Three operators are used, [, [[ and $. In this chapter we learn each of them, and the traps that can hide a record from us. At the end, we use them to prepare an exception report on the payment register of a division.

In later chapters we will mostly use the dplyr functions filter() and select() for tables. But they are built on the ideas of this chapter. Base R subsetting is still needed every day, for vectors, lists and quick checks.

2.1 Our data, a payment register

We will learn most of the ideas on small vectors, so that each result is easy to follow. But the real use of subsetting is on a register. So let us also create the payment register of an imaginary works division, Amarpur Division, for the first seven months of 2024-25. It has 15 payments. A few problems have been planted in it, for us to find at the end of the chapter.

payments <- data.frame(

2.2 Subsetting vectors

Let us start with vectors, the basic objects of R. To subset a vector, we use [. We will use the following vector x. It holds the names of six employees of an office, in the order of their employee numbers. The names start with the letters A to F.

x <- c('Anil', 'Bharati', 'Chetan', 'Deepa', 'Esha', 'Farhan')

2.2.1 Subsetting through a vector of positive integers

Subsetting with positive integers gives the elements at those positions (indices). See this.

# fourth element
x[4]
[1] "Deepa"
# third to fifth element
x[3:5]
[1] "Chetan" "Deepa"  "Esha"  
# first and third element
x[c(1,3)]
[1] "Anil"   "Chetan"

Try this. Check what happens when the integer vector has repeated integers, like x[c(1, 1, 2)].

2.2.2 Subsetting through a vector of negative integers

Subsetting with negative integers gives all the elements except those at the given positions. See this.

# all elements except that at fourth
x[-4]
[1] "Anil"    "Bharati" "Chetan"  "Esha"    "Farhan" 
# all elements except third to fifth
x[-(3:5)]
[1] "Anil"    "Bharati" "Farhan" 
# all elements except first and fifth
x[-c(1,5)]
[1] "Bharati" "Chetan"  "Deepa"   "Farhan"

Try this. Subset with a vector having both positive and negative integers in your console, and check what happens.

2.2.3 Subsetting through a logical vector

We can also subset a vector with another vector of logical values, TRUE and FALSE. The result has only the elements at the places which are TRUE.

# First, third and fifth element only
x[c(TRUE, FALSE, TRUE, FALSE, TRUE, FALSE)]
[1] "Anil"   "Chetan" "Esha"

Recycling is an important idea in subsetting with a logical vector. If the logical vector is shorter, it is repeated up to the length of the vector being subset. Thus, x[TRUE] gives the whole of x.

x[TRUE]
[1] "Anil"    "Bharati" "Chetan"  "Deepa"   "Esha"    "Farhan" 
x[c(TRUE, FALSE)] # will give elements at odd indices
[1] "Anil"   "Chetan" "Esha"

Subsetting with a logical vector is the most important and most used method, because the logical vector can come from a condition. A comparison like amounts > 50000 gives a logical vector, which then picks out the elements meeting the condition. This is how every exception report begins. Let us take the amounts of five bills, named by their bill numbers, and pick out those above ₹50,000.

amounts <- c(B01 = 42000, B02 = 125000, B03 = 9800, B04 = 51000, B05 = 50000)
amounts > 50000
  B01   B02   B03   B04   B05 
FALSE  TRUE FALSE  TRUE FALSE 
amounts[amounts > 50000]
   B02    B04 
125000  51000

Notice that B05, of exactly ₹50,000, is not picked. “Above” a limit and “up to” a limit must be written as > and <=, as the rule says.

Two related functions are very useful. which() gives the positions (and names) of the TRUE values. %in% checks whether each element is in a given set.

which(amounts > 50000)
B02 B04 
  2   4 
names(amounts)[names(amounts) %in% c("B02", "B05", "B09")]
[1] "B02" "B05"

Missing values in a condition. What if a value is missing? A comparison with NA gives NA, and subsetting with NA gives an NA element in the result.

amounts["B03"] <- NA
amounts[amounts > 50000]
   B02   <NA>    B04 
125000     NA  51000

The bill B03, whose amount is missing, appears in the result as <NA>. It is neither above nor below the limit. To get only the bills which truly meet the condition, wrap the condition in which(), which ignores NA. And to look at the missing ones separately, use is.na().

amounts[which(amounts > 50000)]
   B02    B04 
125000  51000 
amounts[is.na(amounts)]
B03 
 NA
WarningCaution

In an exception report, records with a missing value in the tested column are neither exceptions nor clean. Report them separately, as we did with is.na(). Never let them silently fall into either group. We will see the same trap with dplyr::filter() in Chapter 13.

2.2.4 Subsetting through a character vector

This method is used when the vector has names. We pass the wanted names inside []. Let us take the number of bills received from four divisions in a month.

# let us create a named vector `y`
y <- c(Amarpur = 12, Belapur = 7, Chandpur = 15, Devipur = 9)
# display `y`
y
 Amarpur  Belapur Chandpur  Devipur 
      12        7       15        9 
# subset elements named `Amarpur` and `Chandpur`
y[c('Amarpur', 'Chandpur')]
 Amarpur Chandpur 
      12       15

Note that we have used quotes above. We can also use names saved in another variable. See this.

var <- c('Belapur', 'Devipur')
# subset those elements from `y` which are named as per `var`
y[var] # notice that since `var` is a variable, we have not used quotes.
Belapur Devipur 
      7       9

As with positive integers, repeated names give repeated values.

y[c("Amarpur", "Amarpur", "Chandpur", "Amarpur")]
 Amarpur  Amarpur Chandpur  Amarpur 
      12       12       15       12

A name which is not in the vector gives NA, with the name <NA>. So a misspelt name does not give an error. It quietly gives a missing value.

y[c("Belapur", "Bellapur")]
Belapur    <NA> 
      7      NA

The other two methods are not used often. But they are worth knowing for debugging, because sometimes the vector you subset with turns out to be NULL or zero.

2.2.5 Subsetting through nothing

Subsetting with nothing, that is with an empty [], gives the whole vector.

x[]
[1] "Anil"    "Bharati" "Chetan"  "Deepa"   "Esha"    "Farhan"

2.2.6 Subsetting through zero

Subsetting with NULL or 0 gives a vector of length zero.

x[NULL]
character(0)
y[0]
named numeric(0)
is.null(x[NULL])
[1] FALSE

It is interesting to note that subsetting with NULL does not give NULL. It gives a vector of length zero, of the same type.

2.3 Subsetting matrices and arrays

We can subset structures with more dimensions (matrices with 2 and arrays with more) using (i) one vector for each dimension, (ii) a single vector, or (iii) a matrix.

Let us first create a 5x5 matrix mat, with elements named \(A_{mn}\), where m is the row number and n the column number. The labels make it easy to see which element each method picks.

     [,1]  [,2]  [,3]  [,4]  [,5] 
[1,] "A11" "A12" "A13" "A14" "A15"
[2,] "A21" "A22" "A23" "A24" "A25"
[3,] "A31" "A32" "A33" "A34" "A35"
[4,] "A41" "A42" "A43" "A44" "A45"
[5,] "A51" "A52" "A53" "A54" "A55"

2.3.1 Indexing through multiple vectors

This extends all the methods explained for vectors. We give one vector for each dimension, separated by a comma, rows first. A blank, like subsetting with nothing above, returns that dimension complete.

# first and second row with third and fifth column
mat[1:2, c(3,5)]
     [,1]  [,2] 
[1,] "A13" "A15"
[2,] "A23" "A25"
# third to fifth column, all rows
mat[,3:5]
     [,1]  [,2]  [,3] 
[1,] "A13" "A14" "A15"
[2,] "A23" "A24" "A25"
[3,] "A33" "A34" "A35"
[4,] "A43" "A44" "A45"
[5,] "A53" "A54" "A55"
# all columns except third
mat[, -3]
     [,1]  [,2]  [,3]  [,4] 
[1,] "A11" "A12" "A14" "A15"
[2,] "A21" "A22" "A24" "A25"
[3,] "A31" "A32" "A34" "A35"
[4,] "A41" "A42" "A44" "A45"
[5,] "A51" "A52" "A54" "A55"
# Odd rows, all columns
mat[c(TRUE, FALSE),]
     [,1]  [,2]  [,3]  [,4]  [,5] 
[1,] "A11" "A12" "A13" "A14" "A15"
[2,] "A31" "A32" "A33" "A34" "A35"
[3,] "A51" "A52" "A53" "A54" "A55"

The idea can be extended to a named matrix also.

# First create a named matrix
rownames(mat) <- paste0("Row", 1:5)
colnames(mat) <- paste0("Col", 1:5)
mat
     Col1  Col2  Col3  Col4  Col5 
Row1 "A11" "A12" "A13" "A14" "A15"
Row2 "A21" "A22" "A23" "A24" "A25"
Row3 "A31" "A32" "A33" "A34" "A35"
Row4 "A41" "A42" "A43" "A44" "A45"
Row5 "A51" "A52" "A53" "A54" "A55"
# filter desired rows/columns
mat[c("Row1"), c("Col2", "Col3")]
 Col2  Col3 
"A12" "A13"

You may have noticed in the above example that subsetting a matrix may return an object with fewer dimensions. Here a single row of a matrix came back as a vector. The argument drop controls this. It is TRUE by default, which can introduce bugs in code which expects a matrix. Use drop = FALSE to keep the dimensions.

mat[c("Row1"), c("Col2", "Col3"), drop=FALSE]
     Col2  Col3 
Row1 "A12" "A13"
#check this
dim(mat[c("Row1"), c("Col2", "Col3"), drop=FALSE])
[1] 1 2
#versus this
dim(mat[c("Row1"), c("Col2", "Col3")])
NULL

2.3.2 Subsetting through one vector

Matrices and arrays are, at their core, vectors with dimensions attached. So subsetting them with a single vector treats them as plain vectors, counting down the columns. It works exactly as for vectors.

mat[c(1, 10, 15, 25)]
[1] "A11" "A52" "A53" "A55"
# OR
mat[c(TRUE, FALSE)]
 [1] "A11" "A31" "A51" "A22" "A42" "A13" "A33" "A53" "A24" "A44" "A15" "A35"
[13] "A55"

2.3.3 Subsetting through a matrix

We can also subset with an integer matrix having one column for each dimension. To pick elements from a matrix, we need a 2-column matrix. The first column gives the row number and the second the column number of each element. See this.

selection_matrix <- matrix(c(1,1, # Element at Row 1 Col 1
                             2,2, # Element at Row 2 Col 2
                             3,3), # Element at Row 3 Col 3
                           ncol = 2,
                           byrow = TRUE)
mat[selection_matrix]
[1] "A11" "A22" "A33"

2.4 Subsetting lists

Lists can be subset with [], [[]] or $. Let us take them one by one, to understand the difference. An auditor often keeps the pieces of one inspection together in a list. Let us make such a list of 4 elements. The first is a vector of four bill amounts. The second is a matrix of the expenditure of four divisions in each quarter, in ₹ lakh. The third is a list with the name of the office and whether it has been inspected. The fourth is a data frame of four bills. For now, the list has no names.

quarterly <- matrix(c(42.5, 18.0, 33.1, 27.4,
                      51.2, 20.4, 30.8, 25.9,
                      47.9, 22.7, 35.6, 29.3,
                      96.3, 41.5, 38.2, 61.8),
                    nrow = 4,
                    dimnames = list(c("Amarpur", "Belapur", "Chandpur", "Devipur"),
                                    c("Q1", "Q2", "Q3", "Q4")))

my_list <- list(
  c(42000, 125000, 9800, 51000),                                  # first element
  quarterly,                                                      # second element
  list("Amarpur Division", TRUE),                                 # third element
  data.frame(bill = c("B01", "B02", "B03", "B04"),
             amount = c(42000, 125000, 9800, 51000))              # fourth element
)
# display the list

2.4.1 Subsetting lists with []

Subsetting a list with [] always gives a list, containing the chosen element(s).

my_list[2]
[[1]]
           Q1   Q2   Q3   Q4
Amarpur  42.5 51.2 47.9 96.3
Belapur  18.0 20.4 22.7 41.5
Chandpur 33.1 30.8 35.6 38.2
Devipur  27.4 25.9 29.3 61.8
class(my_list[1])
[1] "list"

All the ideas of vector subsetting work here too. The result is always a list, of one or more items.

2.4.2 Subsetting lists with [[]]

Subsetting a list with [[]] returns the item itself, of whatever type it is.

my_list[[2]]
           Q1   Q2   Q3   Q4
Amarpur  42.5 51.2 47.9 96.3
Belapur  18.0 20.4 22.7 41.5
Chandpur 33.1 30.8 35.6 38.2
Devipur  27.4 25.9 29.3 61.8
class(my_list[[4]])
[1] "data.frame"

Notice the difference between the outputs of my_list[2] and my_list[[2]] in the above two code blocks. A common way to remember it is this. If the list is a train, [ gives a shorter train of the chosen carriages, while [[ gives the contents of one carriage.

[[ takes only one item at a time. Check my_list[[1:2]] in your console. The result is not the first two items. It is the second element of the first item, because [[ with a vector digs one level deeper for each value.

2.4.3 Chaining or multiple subsetting

We can subset the result of a subset again, by chaining two or more of the methods discussed here.

# third element of second element
my_list[[2]][3] # recall that by default a matrix is filled by column
[1] 33.1
# or
my_list[[2]][1:3, 2:4]
           Q2   Q3   Q4
Amarpur  51.2 47.9 96.3
Belapur  20.4 22.7 41.5
Chandpur 30.8 35.6 38.2
# or, by names
my_list[[2]]["Devipur", "Q4"]
[1] 61.8

The first result is the expenditure of Chandpur in the first quarter, the third value counting down the first column.

2.4.4 Subsetting with $

$ is a shorthand operator. x$y is roughly equivalent to x[["y"]]. To check this let us give our list some names.

names(my_list) <- c("amounts", "quarterly", "office", "bills")
# Now see
my_list$amounts
[1]  42000 125000   9800  51000
my_list$bills$amount
[1]  42000 125000   9800  51000

Notice that $, like [[, returns the item itself, not a list.

Another difference between [[ and $ is partial matching. With $, R accepts the beginning of a name, while [[ needs the exact name. See this.

my_list$amo
[1]  42000 125000   9800  51000
my_list[['amo']]
NULL
WarningCaution

Partial matching saves typing, but can pick up the wrong column silently. It is safer to always type names in full. (Tibbles, which we will use later, do not allow partial matching, and give a warning instead.)

2.5 Data frames

As we know, data frames are lists whose elements (columns) all have the same length. So all the rules for subsetting lists apply to data frames. In addition, data frames can be subset like matrices, with rows and columns. Let us use our payment register.

head(payments) # head() shows the first six rows
  voucher_no       date            vendor       head amount
1  PV/24/001 2024-04-05    Sharma Traders Stationery  18500
2  PV/24/002 2024-04-12      Kaveri Infra      Works 640000
3  PV/24/003 2024-04-19  Om Sai Suppliers    Repairs  42300
4  PV/24/004 2024-05-03 Laxmi Electricals Electrical  96000
5  PV/24/005 2024-05-17      Kaveri Infra      Works 500000
6  PV/24/006 2024-06-07    Sharma Traders Stationery     NA
# list type subsetting
payments[[5]]  # fifth column, as a vector
 [1]  18500 640000  42300  96000 500000     NA  38750 -12500 812400  27600
[11] 115000 455000  64200  21900 735000
payments[5] |> head()  # fifth column, as a data frame
  amount
1  18500
2 640000
3  42300
4  96000
5 500000
6     NA
# matrix type
payments[1:4, 2:3] # first four rows with second & third columns
        date            vendor
1 2024-04-05    Sharma Traders
2 2024-04-12      Kaveri Infra
3 2024-04-19  Om Sai Suppliers
4 2024-05-03 Laxmi Electricals

Remember

  1. Subsetting a data frame with one index works as for lists. df[5] gives a data frame with the fifth column. df[[5]] or df$amount gives the column itself, as a vector.
  2. Subsetting with two indices, df[rows, columns], works as for matrices. If only one column is chosen, the result drops to a vector, unless we give drop = FALSE.

Let us see the second point.

# Default
payments[1:5, 5]
[1]  18500 640000  42300  96000 500000
# using drop argument
payments[1:5, 5, drop = FALSE]
  amount
1  18500
2 640000
3  42300
4  96000
5 500000

Tibbles never drop to a vector this way, which is one reason they are safer in code.

Rows meeting a condition. The most common use of matrix type subsetting is to pick the rows meeting a condition, and some columns. Let us pick the payments above ₹5 lakh.

payments[payments$amount > 500000, c("voucher_no", "vendor", "amount")]
   voucher_no       vendor amount
2   PV/24/002 Kaveri Infra 640000
NA       <NA>         <NA>     NA
9   PV/24/009 Kaveri Infra 812400
15  PV/24/015 Kaveri Infra 735000

Look at the second row of the result. It is full of NAs, with the name NA. This is the same NA trap we saw with vectors, and it is worse here. Voucher PV/24/006 has no amount, so the condition is NA for it. Base R returns a row full of NA, and the voucher number itself is lost. dplyr::filter(), which we will learn in Chapter 13, drops such rows instead. Neither tells you that they existed. So check sum(is.na(...)) on the tested column first, and wrap the condition in which().

sum(is.na(payments$amount))
[1] 1
payments[which(payments$amount > 500000), c("voucher_no", "vendor", "amount")]
   voucher_no       vendor amount
2   PV/24/002 Kaveri Infra 640000
9   PV/24/009 Kaveri Infra 812400
15  PV/24/015 Kaveri Infra 735000

2.6 Subsetting and assignment

Every kind of subsetting we have seen can also be used on the left of <-, to replace the chosen elements. Here we replace the bills in our list with the first four rows of the register.

my_list$bills <- payments[1:4, c("voucher_no", "amount")]
my_list$bills
  voucher_no amount
1  PV/24/001  18500
2  PV/24/002 640000
3  PV/24/003  42300
4  PV/24/004  96000

This is most useful with a condition. For example, to treat negative amounts in a register as missing, for separate examination, we may write the following.

amt <- c(1200, -350, 4800, 0, -90)
amt[amt < 0] <- NA
amt
[1] 1200   NA 4800    0   NA
TipAudit tip

Replacing values changes the data for good. The original negative amounts in amt are now lost. So before any replacement, keep the data as received in a separate object, and work on a copy. Then you can always show a reviewer what the original values were, and why each one was changed.

Assigning NULL to a list element removes it, as in my_list$office <- NULL.

2.7 Audit use case, an exception report on the payment register

Let us now put the ideas together. The Executive Engineer of Amarpur Division may pass payments up to ₹5 lakh. A payment above that needs the sanction of the Superintending Engineer. Payments may be made only to firms on the approved list. We want an exception report on the register for each rule.

Step 1, count what cannot be tested. Before testing the amounts, we count the payments with no amount.

sum(is.na(payments$amount))
[1] 1
payments[is.na(payments$amount), ]
  voucher_no       date         vendor       head amount
6  PV/24/006 2024-06-07 Sharma Traders Stationery     NA

There is 1 such payment, voucher PV/24/006. It cannot be tested against the limit, so it goes into the report on its own.

Step 2, payments beyond the Executive Engineer’s power. We keep the condition inside which(), and choose the columns for the report.

above_limit <- payments[which(payments$amount > 500000),
                        c("voucher_no", "date", "vendor", "amount")]
above_limit
   voucher_no       date       vendor amount
2   PV/24/002 2024-04-12 Kaveri Infra 640000
9   PV/24/009 2024-07-26 Kaveri Infra 812400
15  PV/24/015 2024-10-25 Kaveri Infra 735000

There are 3 such payments, all to Kaveri Infra, for a total of ₹21.87 lakh. Voucher PV/24/005, of exactly ₹5 lakh, is within the power and rightly not listed.

Step 3, payments to firms not on the approved list. %in% tells us whether each firm is on the list, and ! turns TRUE into FALSE and the other way round. So !payments$vendor %in% approved is TRUE for the firms not on the list.

not_approved <- payments[!payments$vendor %in% approved,
                         c("voucher_no", "date", "vendor", "head", "amount")]
not_approved
  voucher_no       date          vendor    head amount
7  PV/24/007 2024-06-21 Raj Enterprises Repairs  38750

Step 4, amounts that need a closer look. A negative amount in a payment register is unusual. It may be a recovery entered in the wrong place.

payments[which(payments$amount < 0), c("voucher_no", "vendor", "amount")]
  voucher_no         vendor amount
8  PV/24/008 Patel Hardware -12500

Step 5, put the report together. A named list keeps the pieces of the report together, ready to be exported in Chapter 9.

exceptions <- list(
  above_limit    = above_limit,
  not_approved   = not_approved,
  amount_missing = payments[is.na(payments$amount), ],
  negative       = payments[which(payments$amount < 0), ]
)
sapply(exceptions, nrow)
   above_limit   not_approved amount_missing       negative 
             3              1              1              1

sapply() applies nrow() to each element of the list, and gives the number of rows in each part. We will learn it in Chapter 7.

What would the auditor do next? For the 3 payments above ₹5 lakh, call for the sanction of the Superintending Engineer. For voucher PV/24/006, ask the division why the register has no amount, and check the voucher itself. For Raj Enterprises, ask on what authority the firm was paid. For the negative entry, trace the recovery to the bill from which it was made. Each answer, with the documents seen, goes into the working papers.

2.8 A suggested workflow

To prepare an exception report from a payment register, an auditor may follow these steps.

  1. Write the condition. Express the audit rule as a comparison, like amount > 500000. This gives a logical vector. Check whether the rule says “above” or “up to” the limit.
  2. Count the missing values first. Check the tested column with sum(is.na(...)). Know how many records cannot be tested before you test the rest.
  3. Pick the exceptions. Subset with the condition wrapped in which(), so that missing values do not slip in as rows of NA.
  4. Report the missing ones separately. Subset with is.na() to list them. They are neither exceptions nor clean.
  5. Keep only the columns needed. For a data frame, use df[rows, columns] with the names of the columns you want in the report. Use drop = FALSE if the result must stay a table.
  6. Check against a list. Use %in% to test whether each value is in a given set, like the approved list of firms. Use ! in front to find those not in the set.
  7. Type names in full. Take out a column with $ or [[ ]] using its full name. Partial matching may pick up the wrong column silently.
  8. Replace with care. Assign to a subset only when needed, like marking negative amounts as NA for separate examination. Do it on a copy, so that the data as received stays unchanged.
  9. Keep the report together. Put the parts of the exception report in a named list, ready to be exported.
ImportantRemember

A condition on a missing value gives NA, not FALSE. Base R then returns a row full of NAs, and the real record is hidden. Always count the missing values in the tested column, and report them separately from the exceptions.
